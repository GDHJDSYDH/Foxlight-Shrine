# 狐影零时 | Foxlight: 00:00 - 06:00

一款支持 **PC 电脑与手机浏览器** 的 2D 俯视角手电筒潜行生存网页小游戏，部署于 GitHub Pages，即开即玩。

👉 **在线游玩（GitHub Pages）**：https://gdhjdsydh.github.io/foxlight-shrine/

---

## 🎮 游戏简介

午夜 `00:00 AM`，少年 **三谷 熊太** 误入寂静的稻荷神社结界。  
优雅又带点危险气息的狐巫女 **稻荷姬 静音（しずね）** 正隐匿于灌木丛、神乐屏风与朱红鸟居柱的阴影里，准备随时从暗处扑出将他留在这里。

握紧手中的战术手电筒、在庭院中搜集发光电池、听辨清脆的铃铛声与晃动的狐尾——**坚持到凌晨 `06:00 AM` 破晓即可获胜！**

---

## ✨ 核心特色

- **真实 2D 射线追踪光影**：手电筒光束会被鸟居、屏风、灌木和祭台真实遮挡并投射盲区阴影。
- **角色定制 HUD 与预警系统**：
  - 左上角还原熊太的**智能手表表盘**，实时显示时间、电量与随静音逼近而飙升的心率 BPM。
  - 静音潜伏在掩体后时会**露出晃动的红白狐尾、在暗处闪烁金瞳并传出立体声清脆铃音**；`02:00 AM` 后还会施放**假狐火**诱敌转身。
- **手电电量与强光爆闪博弈**：
  - 普通照射持续约 `0.6s` 即可逼退静音或直接识破掩体埋伏。
  - 主动释放**强光爆闪**（消耗电量）可在静音突袭瞬间打断扑击并令其眩晕 `2.5s`。
  - 适时关灯可节省电量，但长时间关灯会让静音更加敏锐。
- **双端流畅操控**：
  - **电脑端**：`WASD` / 方向键移动，鼠标控制手电朝向，`左键 / Space` 强光爆闪，`右键 / F` 开关手电，`P / Esc` 暂停。
  - **手机端**：左下角虚拟摇杆移动 + 右下角独立手电朝向摇杆（支持边退边照）+ 爆闪与开关灯按钮。
- **零构建依赖 & 实时合成音效**：纯 HTML5 Canvas + Web Audio API 实时合成心跳、神社铃音、手电开关与夜风音效。

## 🚀 本地运行

直接用任意静态 HTTP 服务器打开项目根目录即可：

```bash
npx serve .
# 或
python -m http.server 8080
```
